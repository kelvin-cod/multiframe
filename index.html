Guia do MultiFrame Workspace

1. 🔒 Segurança de Navegação & Mesma Origem

Navegadores modernos impedem o controle direto de sites externos a partir de outro painel (Same-Origin Policy). Por isso, o Cofre de Credenciais permite que você salve e copie seus dados rapidamente com 1 clique para colá-los nas telas de login.

Dica: Se o seu navegador já possui senhas salvas, o preenchimento nativo funcionará automaticamente ao clicar nos campos dentro das grades.

2. 🚫 O Site não carrega (Tela Branca ou Cinza)?

Muitos sites (como Google, Facebook, GitHub) bloqueiam o carregamento em iFrames através de cabeçalhos de segurança (X-Frame-Options).

Como resolver para uso pessoal:
  1. Instale uma extensão no Chrome/Edge que ignore estes bloqueios (ex: pesquise por "Ignore X-Frame-Options" ou "CORS Unblock" na Chrome Web Store).
  2. Ative a extensão e recarregue esta página. Os sites voltarão a carregar normalmente!

3. 👥 Como usar Contas Diferentes no mesmo site?

Para manter sessões ativas diferentes nos frames para o mesmo domínio, você pode:

  • Usar diferentes subdomínios (ex: conta1.seusite.com, conta2.seusite.com).
  • Utilizar parâmetros na URL (ex: seusite.com?sessao=1).
  • Para desenvolvedores, usar portas diferentes da máquina local (ex: localhost:3000, localhost:3001).

4. 🔍 Recursos Premium do Painel

  • Zoom da Grade (Maximizar): Dê um duplo clique em qualquer painel (ou clique no ícone de expandir) para maximizar o site na tela toda. Repita para retornar.
  • Escala do Conteúdo (Zoom Interno): Ajuste a escala do site no menu de porcentagem para ler páginas completas mesmo em telas pequenas.
  • Persistência Automática: Suas URLs, nomes e dados do cofre ficam gravados no seu navegador. Você pode reabrir a página quando quiser.
